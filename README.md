# vLLM KV Cache 准入调度与队首阻塞优化

基于 vLLM V1 的有界等待队列准入：队首因 KV 容量不足阻塞时，检查有限数量的后续请求，以累计成功绕行次数保护等待请求。

本仓库是依据现存项目资料重新实现的源码工程；历史工程及原始实验产物已丢失。本次还原不编译、不运行性能实验，历史简历指标不作为本仓库的验证结果。

## 工程边界

- `vllm/`：与固定上游同路径的源码覆盖层，保留原引擎调度与页分配流程。
- `upstream.lock`：固定上游提交及覆盖文件的原始 SHA-256。
- 接入基线：[`fa008bd`](https://github.com/vllm-project/vllm/tree/fa008bdccf10f2f31f84553112a227cf1b8947d7)。本仓库不是完整 vLLM 发行包，后续提供源码组装工具。
- 目标模块：无副作用候选查询、W=8 有限窗口、B=8 绕行保护、跨抢占生命周期、负载回放与完整 cohort 指标统计。

上游文件遵循 Apache-2.0，保留版权头。新增实现、借鉴来源和历史结果边界将在对应代码与文档中逐项标明。
